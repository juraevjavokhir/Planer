# Мой день в одной странице

Простой планер на один день: список дел по времени в виде чеклиста.
Весь проект — один файл `index.html`, без сборки и зависимостей.

## Как запустить

Открыть `index.html` двойным кликом в браузере. Всё.

## Что умеет

- Добавление дела с временем (время можно не указывать)
- Автоматическая группировка: Утро / День / Вечер / Без времени
- Отметка выполнения кликом по квадрату, зачёркивание
- Прогресс-бар и счётчик «сделано из всего»
- Фильтры: Все / Осталось / Готово
- Редактирование текста двойным кликом
- Удаление задачи, очистка всех выполненных
- Светлая и тёмная тема (запоминается)
- Всё сохраняется в браузере (localStorage) — данные не пропадают после перезагрузки

index.html   # разметка, стили и скрипт в одном файле

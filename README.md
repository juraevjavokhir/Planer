# Мой день в одной странице

Планер на один день в виде мобильного приложения. Весь проект — один файл
`index.html`: без сборки, без библиотек, без интернета.

## Как запустить

Открыть `index.html` в браузере. На телефоне — во весь экран, на компьютере —
в рамке телефона по центру.

## Экраны

- **Главная** — приветствие, полоса недели, карточка прогресса и список дел
  по времени. У каждой задачи свой цвет, интервал и кнопка «Старт».
- **Фокус** — таймер с кольцом обратного отсчёта, кнопка «+15» минут,
  чеклист подпунктов, «Пауза» / «Завершить».
- **Календарь** — месяц с точками на днях, где есть задачи, и план выбранного дня.
- **Профиль** — имя, счётчики за день, переключатель темы, очистка дня.
- **«+»** — шторка добавления: название, время, длительность, цвет и подпункты.

## Что важно

- Задачи хранятся по датам в `localStorage` — ничего не теряется после перезагрузки.
- Время фокуса считается по-настоящему: таймер пишет потраченные секунды в задачу,
  паузу можно продолжить с того же места.
- Тёмная тема подхватывается из системы и запоминается.

## Проверка

`test/e2e.js` — сценарий на Playwright: 35 проверок через реальный Chromium
(таймер, кольцо, шторка, календарь, тема, сохранение после перезагрузки,
отсутствие ошибок в консоли и горизонтальной прокрутки на 390px).

```bash
npm i playwright-core
node test/e2e.js ./out    # скриншоты кладутся в ./out
```
